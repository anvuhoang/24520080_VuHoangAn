## Lessons Learned

1. **A fast server hides a missing guard.** The lock stops a held key only while the first request is on its way; once the server has answered, every later repeat event passes. The test that reveals it has to answer first and repeat afterwards.
2. **A table lookup is not safe just because the table is a literal.** `KEY_ACTIONS[key]` answers `"constructor"` with a function. A test with the names of `Object.prototype` found it in one run.
3. **A callback that was removed fails late.** Mongoose 8 does not throw when `exec` gets a callback; it rejects the promise, and without a handler Node stops the process. The first probe of the slide 29 code ended that way.
4. **The deck's server code is not a server.** One line, `Swipe.create(req.body)`, lets the client choose the record's id and time and write any text as the action.
5. **Read each surviving mutant before writing a test.** Two of the survivors are the same behaviour seen from two layers (a guard that another guard already makes redundant); a test for them would have asserted nothing.
6. **Say what a tool could not measure.** axe could not measure three arrow glyphs; the log says so and gives the ratio computed from the tokens, instead of reporting "0 problems".
