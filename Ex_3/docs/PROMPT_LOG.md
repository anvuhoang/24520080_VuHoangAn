## Lessons Learned

1. **Passing greps do not prove the behaviour.** After P16 every static check was green (`abort()` in the cleanup, `AbortError` guard, no `alert(`, no hex, build OK), yet the first browser run showed no `(canceled)` requests and a mismatched skeleton height (Audit #01, #02). Run the Checkpoint in a real browser before calling a feature done.
2. **A prompt can contain the bug.** P2 told the AI to wait first and fetch second, and the AI followed it exactly; the defect was in the instruction, not in the generated code. Write prompts from the behaviour you will check ("a request must exist to be canceled"), not only from the steps.
3. **Scaffolding copies its defects.** The missing favicon came from the first `index.html` and was copied into all three exercises (Audit #03, still open). Fix the template once, then re-check every copy; and check small things like the console, not just the feature.
