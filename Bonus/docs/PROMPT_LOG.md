## Lessons Learned

1. **AbortController with Intervals Requires Flag Cancellation**: When aborting an asynchronous operation or timer in a custom hook, calling `controller.abort()` alone is insufficient if an interval is ticking independently. A boolean cancellation flag (`isCancelledRef`) is essential to prevent trailing timer ticks from executing completion callbacks after cancellation (Audit #01).
2. **Synchronous Derivation Beats Redundant Effects**: Attempting to store derived domain state (such as effort impact weights and red flag status) in secondary `useState` synchronized via `useEffect` introduces render lags, stale frames, and race conditions. Synchronous pure function evaluation in render guarantees zero-latency, always-consistent domain calculations (Audit #02).
3. **WCAG Live Region Hygiene**: Using multiple `role="status"` live regions creates cognitive overload and screen reader conflicts. A single, dedicated `<output role="status" aria-live="polite">` element ensures clean, predictable assistive announcements without duplicate vocalizations (Audit #05).
4. **Monotonic Timing Eliminates Background Tab Drift**: Subtracting a fixed time slice per tick (`time - 100ms`) drifts drastically when browsers throttle background tabs. Deriving remaining time via `targetEpoch - Date.now()` maintains true wall-clock accuracy regardless of tab throttling.
5. **Phase Badges Need Redundant Affordances**: Color alone (e.g. red vs green) violates WCAG 1.4.1. Combining distinct border styles (`dashed`, `solid`, `double`, `dotted`) and emoji/text markers ensures phases remain distinguishable in high contrast and grayscale modes.
6. **Strict Guardrails in FSM Reducers Protect Terminal States**: Explicitly enforcing valid transitions and freezing terminal states (`GHOSTED_EXIT`, `SELF_RESPECT_EXIT`) prevents illegal state transitions and guarantees memory cleanup. Kept domain limitations documented via `it.fails` rather than hiding them (Audit #03).
